# Contributing

Bug reports and feature requests may be submitted through GitHub Issues.

Prospective contributions of code, documentation, or other materials require
prior written approval from Rylan Wade. Before opening a pull request, submit a
GitHub Issue describing the proposed contribution. If the proposal is approved,
the applicable contribution terms will be documented in a separate written
agreement before the contribution is accepted or merged.

Kessel is distributed under the
[PolyForm Noncommercial License 1.0.0](LICENSE). This contribution policy is
intended to preserve an unambiguous chain of title and Rylan Wade's exclusive
authority to grant commercial licenses for Kessel. Submission of a proposal or
pull request does not constitute acceptance of a contribution or modify the
rights granted under the license.
